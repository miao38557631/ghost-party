# 玩家鬼魂美术接入

## 实际素材

- Assets/2DTexture/Ghost/Idle/Ghost_Idle_00.png 至 Ghost_Idle_29.png：30 张独立透明 PNG，1223 × 1244；映射到 Ghost_Idle / Idle 状态。
- Assets/2DTexture/Ghost/Walk/ghost_walk_00.png 至 ghost_walk_29.png：30 张独立透明 PNG，1321 × 1299；映射到 Ghost_Walk / Walk 状态。
- 两组均只有同一美术朝向，没有上下左右方向组。素材原始朝右；左右移动使用 SpriteRenderer.flipX，纯上下移动与停止保留上次朝向。不将独立帧当成整张序列图切分。
- 当前没有附身、攻击、受击、冲刺、离开窗帘等额外玩家帧图。这些流程继续沿用现有玩法表现；附身确认成功后隐藏鬼魂可视层，内部 Animator 保持待机，不伪造缺失的动作。

## 导入与基准

统一 Sprite / Single、512 Pixels Per Unit、Full Rect、透明 Alpha、双线性过滤、Clamp、无 mipmap、无损导入。按文件尾部数字排序并检查 00–29 连续。

每组所有帧共用一个基准点，取该组完整 Alpha 包围范围的底部中心；不逐帧裁边、重新居中或缩放。Idle 的共同中心为源图横坐标 517，基线距底部 145；Walk 为横坐标 535.5，基线距底部 172。两组有效高度接近，保持统一像素比例，保留美术本身的漂浮、倾斜和轮廓变化。

没有找到美术帧率说明，暂用 24 FPS；30 帧一循环约 1.25 秒，最后增加首帧关键帧以闭环。帧图本身不修改，原 TextureImporter GUID 保留。

## 运行结构

InvisibleGhost 控制根保留原名称、0.76 缩放、SphereCollider、位置与交互引用。根节点的旧 MeshRenderer 关闭，原 Light 保留。独立 Visual 子物体使用 SpriteRenderer、Animator 和 GhostPlayerVisual；动画曲线只驱动 SpriteRenderer.sprite，不驱动任何 Transform。

GhostPlayerAvatar.Create 为白盒一、二楼和旧原型提供统一入口，优先复用已有 InvisibleGhost，避免重复玩家。资源为 Assets/Resources/Player/GhostVisual.prefab；对应控制器 GhostLocomotion.controller 使用 IsMoving 布尔参数即时切换 Idle / Walk，均循环播放。

WhiteboxPlayable 和 GhostPartyPrototype 将已经读取的移动向量传给 GhostPlayerAvatar.SetMovement。Visual 不读取新的输入，也不新增移动控制或物理系统；进入特写时传入零移动，返回后沿用原控制。只有 Visual 跟随 Camera.main 旋转，根坐标系不旋转。

## 可调整参数

在 GhostVisual.prefab 的 GhostPlayerVisual 组件中调整：

- World Height：默认 1.35 个世界单位。
- Local Offset：默认 (0, -0.18, 0)，控制漂浮高度，不移动根碰撞体。
- Idle Playback Speed / Walk Playback Speed：默认 1，可独立调整两段临时帧率的播放倍率。
- Movement Threshold：默认 0.01，使用已有移动向量判断待机/行走。
- Face Camera：默认开启，只作用于 Visual。

Reference Sprite Height 是所有源图有效 Alpha 高度的固定参考，不应按当前帧修改，否则会出现伸缩抖动。

材质使用当前内置渲染管线的 Sprites/Default，白色无额外染色。SpriteRenderer 保持默认深度规则与 Pivot 排序点，未使用永远置顶或遮挡穿透材质；现有白盒墙体遮挡系统保持原样。

## 左右翻转与附身显隐（2026-10-30）

- GhostPlayerVisual 接收原有世界 X/Z 移动向量。横向输入超过 Facing Deadzone 时按当前镜头的屏幕横向投影设置 SpriteRenderer.flipX；停止或纯 W/S 输入保留上次方向。Artwork Faces Right 默认为 true，原始帧图朝右。Visual 的 LateUpdate 在 Animator 后重申翻转，动画片段仍只驱动 sprite。
- 不使用根节点负缩放，不改变 InvisibleGhost 的位置、朝向、碰撞或移动输入。
- 统一入口 GhostPlayerAvatar.SetVisible(player, visible) 由所有附身系统复用；GhostPlayerVisibility 保留各 Renderer、Light 与 TrailRenderer 原状态，隐藏时同步关闭这些可视效果，恢复时按原值还原，旧占位渲染器不会被重新打开。视觉物体和 Animator 始终保持激活。
- 真实流程在 GhostPartyPrototype.BeginPrank 正式设置 Closeup 后当帧隐藏，未通过现有距离/目标/状态判断的 E 不会调用隐藏。ResetPrank 与动作失败重试期间持续隐藏。完成、NPC 挣脱及 Esc 共用 ReturnToExplore，沿用原位置返回后恢复外观与 Idle；方向状态保留。
- 新附身目标在成功提交状态时调用 SetVisible(player, false)，自由探索恢复时调用 SetMovement(player, Vector3.zero) 后 SetVisible(player, true)。不要直接在 E 按下时隐藏，也不要禁用玩家根物体。
- 工程菜单 Ghost Party > Player > Run Ghost Art Play Checks 已扩展左右/停步/上下朝向、同帧隐藏、内部重试、成功/挣脱/共用退出路径和多次进入退出检查。程序化调用退出路径不等于物理 Esc 按键测试。
