# 基础玩法与窗帘 · 玩法说明 v1.1

更新日期：2026-10-09

本文描述目标玩法，仅包含基础操作与窗帘恶作剧，不展开其他恶作剧和物品交互系统。新轨迹玩法、流程调整等还需开发，不能把本文当作已实现功能清单。

## 1. 基础玩法

玩家看操作提示，跟着音乐完成恶作剧。

> 看当前操作与下一步 → 按节奏操作 → 成功进入下一步 → 失败重试当前操作 → 连续漏拍太多，NPC 挣脱。

提示告诉玩家三件事：**做什么、什么时候做、持续多久。** 不要求读谱，只需要跟拍。

- 本阶段只做整拍操作，暂不做半拍。
- 只显示当前操作和下一步预告，不显示一长串谱面。
- 自动演出时不用操作，也不计算漏拍。
- 使用当前 Unity 的最终 BGM，进入挑战留准备时间后从整拍开始。
- 提示与判定跟同一音乐节奏；简单模式比普通模式更宽松，具体数值试玩调整。

## 2. 三种基础操作

| 基础操作 | 键鼠 | Xbox 手柄 |
|---|---|---|
| 点按 | 点一下左键，卡上目标拍 | 点按 A |
| 按住与松开 | 按住左键，维持指定拍数，按提示松开 | 按住 A，按提示松开 |
| 沿轨迹移动 | 在起点圆按住左键，拖着圆沿轨迹到终点 | RT＋左摇杆；新版轨迹控制待适配 |

“定向移动”和“路径移动”合并为沿轨迹移动，直线和转弯只是轨迹不同。连续点按、左右交替、拖动后保持按住是基础操作的组合。

### 沿轨迹移动怎么玩

画面显示起点圆、轨迹和终点。玩家按住起点圆，沿线拖动，圆跟随鼠标显示自己的操作位置。按提示在相应拍点完成动作，不能跳过中间轨迹直接到终点。

不再允许随便在画面某处起手、只朝一个方向拖够距离。轨迹圆是可拖动对象，窗帘旁的白底图标只是提示，两者不要混淆。

### 手柄操作

RT 对应按住鼠标左键，左摇杆负责移动。只有 RT 按住时移动摇杆，才触发移动操作；松 RT 对应松开左键。

RT 按住时，摇杆回中也正常参与移动判定，不自动豁免。按玩家拇指持续操纵摇杆来设计，不要求每步离开摇杆。新版如何抓起点圆、控制圆沿线走，由程序给适配方案再试玩。

## 3. 成功与失败

- 卡上拍并完成当前要求，进入下一步。不把太早的输入存起来自动判成功。
- 失败不跳操作，音乐继续，下一目标拍重试。
- 当前轨迹中途失败，整条当前轨迹重来，不从中间补，也不重启整个窗帘挑战。
- 拖动失败有一拍的回弹／恢复，随后继续尝试。
- 最后甩出不要求额外松手才能成功。

轨迹偏离多少算失败、重试怎么重新抓圆、连续轨迹如何接起来，由程序先做简单方案，试玩后调整，不在这里展开技术边界。

## 4. 窗帘完整流程

先吸引 NPC、包裹，再扇巴掌，最后蓄力甩飞。共五组挥打：**四组普通左／右＋一组蓄力甩出。**

下表是顺利完成时的相对拍位，失败会增加重试拍。所有移动都用对应方向的可见轨迹表达。

| 拍位 | 玩家做什么 | 演出 |
|---|---|---|
| 1 | 点按 | 窗帘挑动，吸引注意 |
| 2 | 再点按 | 再次吸引注意 |
| 3 | 不操作 | 自动抬帘，1 拍 |
| 4～5 | 不操作 | NPC 靠近，2 拍 |
| 6 | 沿轨迹向右 → | 开始包裹 |
| 7 | 沿轨迹向下 ↓ | 拉紧，完成包裹 |
| 8 | 不操作 | 包裹完成演出，1 拍 |
| 9～10 | 沿轨迹左、右 | 第一组巴掌 |
| 11～12 | 沿轨迹左、右 | 第二组巴掌 |
| 13～14 | 沿轨迹左、右 | 第三组巴掌 |
| 15～16 | 沿轨迹左、右 | 第四组巴掌 |
| 17 | 沿轨迹向左下 ↙ | 最后一组：开始蓄力 |
| 18 | 保持按住，提示 `-` | 维持蓄力 |
| 19 | 沿轨迹向右上 ↗ | 甩出，NPC 飞出 |

蓄力共两拍：先左下拖动，再保持按住一拍，不需要再按一次。保持期间允许轻微抖动，明显移开或松手则失败，从左下蓄力重来。不新增力度条。

保持拍属于玩家操作，不是空拍或自动演出；成功同样清零漏拍。`-` 暂时表示保持按住，正式图标后续设计。

## 5. 操作与表演的手感

- 玩家有效操作时，窗帘出手和轻微镜头反馈立即响应。
- 成功后接上击中、NPC 受击和巴掌音效，不重新从头出手。击中与音效尽量贴合拍点，容错范围内稍晚完成允许略晚击中。
- 失败不播放击中和受击效果；已经出手就打空或回弹。没有操作，不凭空出手。
- 成功立即切换下一操作提示，不等旧动画结束。连续操作要顺滑跟手。
- 镜头角度固定，按操作方向轻微偏移，有上限；成功保留偏移，失败回弹。
- 点按轻微拉近再恢复，最后一击更明显。

动画、镜头与音效的具体参数由制作同学参考现有效果，实机调整。

## 6. 漏拍与挣脱

NPC 旁有四格绿色圆环，表示挣脱进度。

| 难度 | 连续漏几拍走一格 | 四格满 |
|---|---|---|
| 普通 | 2 拍 | 连续漏 8 拍，挣脱 |
| 简单 | 3 拍 | 连续漏 12 拍，挣脱 |

成功一次就全部清零，不是整轮累计。合法保持按住也算操作，不因为没有新点击就记漏拍。自动演出不增加也不清零进度。

圆环每走一格，镜头猛拉近、稍收回并保持压力；成功清零后退回。满格时 NPC 挣脱离开，镜头返回地图，不播放成功甩飞。

明显卡顿造成的错拍不惩罚玩家，恢复后留重新跟拍的时间；具体容错由程序处理、试玩验证。

## 7. 提示表现

| 提示 | 表现 |
|---|---|
| 窗帘可玩提示 | 未挑战时跟拍轻微挑动 |
| E 圆圈 | 靠近时白底黑 E，跟拍放大缩回 |
| 进入特写 | E 换操作图标，提示稍向下移，不重叠 |
| 当前操作大圆 | 白底黑图标，手动图标常驻，跟拍快速放大缩回 |
| 自动演出 | 主圆内部空白，不放小点 |
| 下一步小圆 | 主圆左下，70% 不透明度，不跟拍跳；只预告紧邻下一步 |
| 下一步自动／没有下一步 | 预告小圆整体隐藏，不跳到更后的操作 |
| 保持按住 | 暂用 `-`，例如左下拖动时预告 `-`，保持时预告右上 |
| 顶部节拍辅助 | 默认关闭，可开启；圆形高亮变细长线，关闭不影响玩法 |
| 手柄提示 | 切换到对应按钮／操作图标，不继续显示鼠标按键文字 |

## 8. 制作要求

以窗帘为例，操作类型、轨迹、顺序、重复次数、持续拍数和演出时间要方便修改；改动后提示、判定和演出一起更新。

实现方式和调参由程序决定。这份文档只讲怎么玩，不规定字段、坐标采样、摇杆阈值或技术结构。先做能玩的简单版本，再根据实机手感打磨。

当前 Unity 仍主要是旧自由拖动原型，新轨迹、两拍蓄力、新流程及手柄适配不能标为已经完成。游戏代码已移交程序，本轮只维护玩法文档及网页说明，不修改 Unity 代码。
