# Xbox 手柄输入与震动

适用 Unity 2022.3.62f2c1，Input System 1.7.0。Project Settings > Player > Active Input Handling 使用 **Both**；首次切换后需要重启 Unity。旧 StandaloneInputModule 继续处理键鼠 UI，游戏输入由 GhostInput 读取 Input System 的设备状态。

## 操作

| 阶段 | Xbox | 键鼠 |
| --- | --- | --- |
| 自由探索 | 左摇杆 | WASD / 方向键 |
| 附身 / 楼梯互动 | A | E |
| 节拍点按 | A | 左键 / Space |
| 方向操作 | 保持 RT，推动左摇杆 | 保持左键，沿箭头方向滑动；保留原键盘方向快捷输入 |
| 蓄力保持 | 延续抓握并保持 RT | 延续左键抓握 |
| 退出附身 | B | Esc |

进入附身的 A 当帧被消耗，松开后才能接受下一次 A。方向操作仍用原有方向判定和 DSP 节拍时间：在拍圈提示时推动摇杆，方向到位后继续保持 RT，等待判定。最终甩出沿用现有规则，右上方向到位并保持到拍点即可成功，随后可以松开。

左右连挥可以持续按住 RT 直接换向。摇杆一次持续偏转只产生一次方向事件；同方向再次操作要先回中。输入窗口之前的偏转不会缓存到之后的拍点，需要回中或换向后再做。蓄力阶段可以把摇杆回中，但 RT 不可松开；松开会沿用现有失败重试。

## 可调参数

在 Project 中选择 `Assets/Resources/Input/GhostInputSettings.asset`，可通过 Inspector 永久调整：

- 移动死区、提示设备切换阈值、方向触发/回中阈值及方向角滞回。
- RT 按下和松开阈值。
- 三档震动的低频、高频和持续毫秒数。

| 确认成功事件 | 低频 | 高频 | 毫秒 |
| --- | --- | --- | --- |
| 敲窗点按 | 0.10 | 0.20 | 45 |
| 左右挥击 | 0.25 | 0.38 | 65 |
| 最终甩出 | 0.65 | 0.45 | 140 |

震动在 TryCurtainAction 的成功分支中触发；包裹、保持、失败、漏拍和重复按住不会产生额外命中震动。记录动作来源手柄并对该实例调用 SetMotorSpeeds，不依赖可能被其他设备更新的 Gamepad.current。键鼠完成动作不会震动闲置手柄。

震动用 realtimeSinceStartupAsDouble 到期停止。B/Esc 退出、重试重置、挣脱、Time.timeScale 暂停、编辑器暂停、应用暂停、失焦、场景切换/卸载、组件停用、退出 Play、程序集重载以及设备禁用/断连/移除均清理马达。设备重连也会重置马达。

## 兼容性处理

- A/B/RT/左摇杆提示跟随明确的实际操作切换；死区内的摇杆噪声不会切换提示或移动角色。
- 保留 CharacterController 移动、统一附身入口、节拍时钟、动作顺序、HUD 和原有失败重试。
- InputManager 中两条旧手柄 Horizontal/Vertical 轴改为 LegacyJoystickHorizontal/Vertical；Submit/Cancel 解除 joystick button 0/1 备用绑定。这样手柄只经新输入适配器参与游戏，A/B 不会同时操作旧 UI 的 Submit/Cancel。键鼠轴及 UI 键位保留。
- 未迁移为 InputSystemUIInputModule，也未增加第二个 EventSystem。

## 自动检查

退出 Play 后执行 **Ghost Party > Input > Run Gamepad and Keyboard Play Checks**。测试使用一楼和 SampleScene，两次独立进入 Play，完成后恢复原编辑场景及 playModeStartScene，不保存测试产生的场景变更。

测试期间会临时禁用 Unity Input System 中原先启用的实体键鼠/手柄，避免真实鼠标替换 Mouse.current 干扰虚拟输入，结束或失败后恢复。

结果在 `Logs/InputSystem/play-checks.json`。测试用虚拟 Gamepad、Keyboard、Mouse 驱动实际生产输入代码和节拍判定，并拦截虚拟设备的 RMBL 命令；不会向实体手柄发送测试震动。覆盖完整流程、A 松开门控、持续偏转去重、RT 连续换向、三档震动次数/设备、键鼠流程、UI 模块以及暂停/失焦/场景/断连清理。

这些结果属于程序化 Unity Play 验证，不能替代实体手柄连接、真实 OS 输入、视觉与马达手感验收。

2026-11-06 最终验证：Unity 原生编译通过，一楼和 SampleScene 共 **203 项断言通过、0 项失败**，包括 F8 面板、语言/难度按钮 EventSystem 回调、UI 点击不穿透到节拍点按。检查结束后恢复原编辑场景与设备状态。

## 最小实体验收

1. 在一楼 Play，连接 Xbox 手柄：左摇杆移动，靠近窗帘按住 A 进入。确认没有自动敲窗；松开 A 再按提示点按，感觉到轻震。切换到鼠标/键盘后，摇杆静置不会把提示抢回。
2. 保持 RT，按箭头推动左摇杆完成包裹及连续左右挥击；持续同方向不应重复触发。左下蓄力后只保持 RT，最后向右上甩出。比较敲窗、普通命中、最终甩出三档力度。
3. 再进入一次，在挥击命中时按 B、暂停/切出窗口或断开手柄，确认马达停止；重连后可以重新操作。再用 WASD、E、左键方向操作和 Esc 完成一次流程；附身后按 F8 显示面板，点击原有语言/难度 UI。

参考：[Unity Input System 1.7 Gamepad 文档](https://docs.unity.cn/Packages/com.unity.inputsystem@1.7/manual/Gamepad.html)。
