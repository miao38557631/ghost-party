## 上下层
两个Scene各自地面为Y=0，北为+Z，X/Z共用叠层图的坐标。叠层时将二层Prefab上移2.2m（暂定楼层高）。生成器会输出叠层核对图，不创建第三个关卡Scene。

## 操作
Play后1总览、2俯视、右键+WASD飞行、Q/E升降、Shift加速、滚轮缩放。
Ghost Party > Level Whitebox菜单可重新生成或校验；重新生成会覆盖两个场景和Prefab，手动改图前请另存场景。
校验检查墙高墙厚、围栏高度、舞池下沉碰撞深度、挑空和脚本引用。

Prototype仍通过原有白盒目录判断隔离；SampleScene未改动。未修改Build Settings。白盒使用Unity内置网格与组件，不依赖ProBuilder。
